# 구현 순서 (/loop로 진행)

사용자 요청(2026-11-22): 세무사가 고객이 준 파일들을 올려 부가세 신고 준비까지 편하게 할 수 있도록, 사용자 관점에서.

## 사용자 흐름 (세무사 화면 기준)
1. 고객 선택 → 신고 건(2026년 1기 확정) 열기
2. 고객이 준 파일들을 한 번에 끌어다 놓기 — 파일 종류 자동 인식(매출 세금계산서 / 매입 세금계산서 / 사업용 카드 매입). 같은 파일 다시 올려도 중복 없음
3. 규칙이 확실한 건 즉시 판정, 애매한 건은 AI가 근거와 함께 제안(진행 단계 실시간 표시)
4. "검토할 것"만 모아 보기 → 키보드로 승인/수정, 같은 가맹점 일괄 적용
5. 신고서 요약(매출세액 − 매입세액 = 납부세액, 불공제 사유별)이 실시간 갱신
6. 결과 Excel 내보내기 / 고객 확인 후 수정본 재업로드 → 차이만 보여 주고 반영
